# Mini Projects

This repository contains a collection of small programming projects that I use to practice and improve my software development skills.

I am currently studying Software Engineering and working primarily with **C#**. The projects in this repository are intended to go beyond regular semester exercises and give me more experience with building complete programs from start to finish.

The focus is not only on making the programs work, but also on improving how I structure, organize, and maintain my code.

---

## Purpose

The main goals of this repository are to:

- Practice C# fundamentals
- Improve object-oriented programming skills
- Become more comfortable designing small applications
- Practice breaking larger problems into smaller methods and classes
- Improve code structure and readability
- Learn how to refactor working code into better designs
- Practice input validation and error handling
- Gain experience using Git and GitHub for project development

Each project is kept relatively small so I can focus on specific programming concepts without introducing unnecessary complexity.

## Development Approach

The projects are built incrementally.

A typical development process looks like:

```text
Create a basic working version
        ↓
Add required features
        ↓
Handle invalid input and edge cases
        ↓
Refactor large methods
        ↓
Move responsibilities into appropriate classes
        ↓
Review and improve the architecture
```

I intentionally avoid immediately using advanced frameworks or libraries when a problem can be solved with basic C#.

The goal is to understand the underlying programming concepts before relying on higher-level abstractions.
